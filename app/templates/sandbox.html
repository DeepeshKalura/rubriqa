Sandbox — 3-way OCR comparison

One handwritten page, three AI readers, one rubric, one human reference.
How to read this sandbox — quick guide for humans

What this page does

You drop in a photo of one student's handwritten page (or pick a bundled sample). The same image is sent through three different AI reading pipelines. Each pipeline produces a transcript of the page, and then the same 5-criteria rubric scores it. When a human-verified golden transcript exists for the page, the page also shows the per-path character error rate (CER, lower is better).

The point is to answer one question: which AI reading path is closest to how a human reads this page, and which one scores closest to what a teacher would award?

The three paths

  • Path A — Vision LLM (strict). A vision model looks at the page and transcribes what it sees. Strict mode: it is told not to invent text that is not visible. Best on English handwritten pages.
  • Path B — Tesseract + LLM. A classic open-source OCR engine (Tesseract) extracts the text first; the LLM then scores that cleaned text. Cheaper and faster, but struggles on non-Latin scripts and cursive.
  • Path C — Vision + Tesseract fusion. Both A and B run. A vision LLM merges the two transcripts using the page image as the referee, producing a human-like reading. A gate automatically skips fusion when Tesseract's output is much longer than vision's (a sign Tesseract is hallucinating noise) — in that case Path C just uses the vision transcript. Best on Marathi pages.

How to judge the numbers

  • Score /50 — total rubric points awarded. The rubric has 5 criteria, each out of 10. Higher is better.
  • Percent — score as a percentage of the total.
  • Confidence — the LLM's self-reported certainty in its own scoring. Treat as a hint, not a guarantee.
  • CER vs golden — character error rate against the human-verified transcript. Lower is better. Roughly: <15% good, 15–40% rough, >40% failed.
  • Tokens / elapsed — cost and latency. Path A cheapest, Path C most expensive.

The rubric (5 criteria, 10 pts each)

  • relevance — how well the proposal fits the chosen theme.
  • feasibility — how realistic it is to build in the student's context.
  • originality — how original / non-trivially-copied the idea is.
  • ai_understanding — how clearly the student explains how AI is used.
  • communication — clarity, structure, and respect for the word-count guidance.
