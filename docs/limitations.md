# Known limitations (honest list)

1. **No real client data has been benchmarked.** All reader/scoring numbers
   come from synthetic pages generated by `scripts/gen_synthetic.py`. Hindi
   handwriting accuracy on real student work is unknown until representative
   samples are evaluated. The architecture makes that a benchmark run, not a
   rewrite: `make bench-readers --data <labeled-folder>`.
2. **The 20k scale test measures the data layer only.** 20,005 submissions /
   200,020 answers were bulk-seeded; no OCR/LLM ran over them. Throughput for
   real handwritten exams is bounded by the reader: roughly 2 s/page
   (tesseract) or 13 s/page (MiniMax vision) measured on synthetic pages.
3. **MiniMax requires internet.** Offline, the Tesseract/PDF paths still work
   and vision pages are marked `deferred` and retried later, but handwriting
   reading degrades to OCR quality.
4. **Google Forms import matches students by the first answer (roll number).**
   A production deployment would let the operator map questions to fields in
   the import UI. OAuth flow itself is implemented; the only untested part
   without your credentials is the live consent redirect.
5. **Question/answer extraction uses the LLM with a regex fallback.** The
   transcript is truncated at 12k characters per submission; very long
   submissions (more than ~10 pages) could lose the tail. Paging through long
   transcripts is the next extraction improvement.
6. **Repair auto-accept threshold is configurable but uncalibrated.** With no
   labeled repair data, `REPAIR_AUTO_ACCEPT_MIN_LEGIBILITY=0.72` is a
   deliberately conservative default; pending repairs are visible in the
   Review queue either way.
7. **Single-operator tool.** No user accounts; the UI is bound to
   `127.0.0.1`. Do not expose port 8090 to a network without adding auth.
8. **Feedback generation is off by default** (`SCORING_ENABLE_FEEDBACK=false`)
   and the feedback prompt is intentionally minimal; it needs calibration on
   real answers before it is useful to students.
9. **No automatic backups.** `./data` (originals/derived) and the
   `exam-eval_pgdata` volume must be copied for backup.
10. **Language support is Hindi + English** (`TESSERACT_LANGS=eng+hin`).
    Other Indic languages are a tesseract language-pack change plus testing.
